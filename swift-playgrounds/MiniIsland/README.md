# 超ミニ島 — Swift Playgrounds 版

Coffee Break の **anno_proto**（Godot）を、Swift Playgrounds で超ミニ体験するサンプルです。

## できること

- 5×5 の島（左下は海）
- 平地をタップ → 畑（最大3つ）
- 2秒ごとに **小麦 +1 × 畑の数**
- 「最初から」でリセット

## iPad での作り方（5分）

### 1. Swift Playgrounds を開く

App Store から **Swift Playgrounds**（無料）をインストール済みなら起動。

### 2. 新しい App を作る

1. **App** タブ（または「アプリ」）
2. **+** → **新規 App**（名前例: `超ミニ島`）

### 3. コードを貼り替える

1. 左のファイル一覧で **ContentView.swift** を開く
2. 中身を **全部削除**
3. このフォルダの `ContentView.swift` を **丸ごとコピペ**
4. 右上 **▶（実行）** をタップ

`MyApp.swift` など `@main` があるファイルは、そのまま `ContentView()` を表示する形で OK です。

### 4. 遊び方

- 🟩 平地をタップ → 🌾 畑
- 小麦の数字が 2 秒ごとに増える
- 畑は 3 まで

## うまく動かないとき

| 症状 | 対処 |
|------|------|
| ビルドエラー | `ContentView.swift` だけにコードがあるか確認。重複した `@main` が2つないか |
| タップが効かない | シミュレータではなく **実機 iPad** で試す |
| 数字が増えない | 畑を1つ以上置く。2秒待つ |

## anno_proto（Godot）との関係

| 項目 | Swift 超ミニ | Godot anno_proto |
|------|-------------|------------------|
| マップ | 5×5 | 大きい島 |
| 畑 | タップで最大3 | 自由配置 |
| 風車・パン屋 | なし（メッセージのみ） | あり |
| 本番向け | 学習用 | 本番プロト |

本格的な創世紀1602風は **Godot の anno_proto** を続けるのがおすすめです。
