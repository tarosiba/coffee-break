### Noema 手元セットアップ（iPad Air 4世代）

| ステップ | おじさんの操作・結果 |
|----------|----------------------|
| 体験モード | **初心者** を選択 |
| モデル | **Qwen 3.5 0.8B**（675MB）をセットアップ・**Ready** |
| 体験モード変更 | **単純** に切り替え（タブが チャット/保存済み/探索/ツール/設定 に） |
| 口調の場所 | **マイ AI** はモデル管理のみ。口調は **チャットの指示** または **設定→思い出を管理** |
| 保存済み | Qwen ロード済み。**埋め込みモデル（639MB）は未DL**（PDF用・未着手） |
| 1通目 | 「こんにちは、日本語で短く答えて」→ 返答あり（「日本大学の教授」等の誤自己紹介） |
| 2通目 | 「今日は雨が続いている。短く励まして」→ **⚠️ オンデバイスモデルのランタイムが応答しませんでした** |
| 思い出 | **思い出を管理** に口調を登録して再試行 → 同様に2通目でランタイムエラー |
| 中断判断 | **受け答え・レスポンスが想像より良くない** → **Noema はいったん中断**（2026/9/10） |
