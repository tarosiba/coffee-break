# 漫画シリーズ原稿：入植前哨ファイル ― 誤った軌道

**ジャンル:** レトロSFテレビドラマ風（1960年代宇宙家族ロビンソン系の**雰囲気**を参考にした**オリジナル**作品）  
**想定:** 全6話×各4〜6ページ  
**執筆状態:** 第1話 **1〜2ページ** を Coffee Break クリエイティブ「入植前哨マンガ」に公開（`src/lib/colonyPrepManga.ts`）。続きは順次追加。  
**作者メモ:** おじさん提供の参考画像＝円盤型船体・キャタピラ探索車・銀色の船内。ロボットは**スター・ウォーズのC-3POのような人型**（オリジナルデザイン）。

### 設定更新メモ（2026-09-25・おじさん指示）

- ロボットは**2体とも人型**。細い金属の肢体・**人の代わりにロケットを操縦できる手**（スロットル、レバー、タッチパネル操作可）。
- **丸い顔**のロボット1体、**四角い顔**のロボット1体。
- 不時着後は**エンジンの一部分が破損**。破損箇所・修理手順の詳細は**これから調査**（物語内でも段階的に判明）。
- 2体とも**宇宙船の修理**に活躍する想定。

### 設定更新メモ（2026-09-25・クルー／冬眠／軟着陸）

- **人間の搭乗員は3名**。長距離航行のため2名は**冬眠（コールドスリープ）**、1名は**先に覚醒したパイロット**（悠真）。
- 翠星入植準備の段階で、**冬眠から通常状態へ戻す工程でトラブル**が発生。**2名は回復できず命を落とす**（原因の詳細は物語内で段階的に調査・未確定でも可）。
- 生き残ったパイロットは**複数の非常事態**（着陸失敗、生命維持、誘導喪失など）に対応する**訓練を受けている**。
- 起動できた**ロボット2体**と協力し、**ロケットの制御を試みる**（操縦席・補助系の分担）。
- 軌道を**大きく外れ**、目標の翠星ではなく**未確認の惑星**へ向かう。**軟着陸を試みる**（完全制御下の着陸ではないが、墜落全損よりはマシな着地を目指す）。
- **漫画本文はまだ書き始めない。**

## ログライン

地球から**新惑星「翠星」**への入植準備を進める前哨船。人間3名と自立型ロボット2体が乗るが、冬眠からの復帰で**2名が命を落とし**、先に目覚めたパイロットだけが残る。非常事態訓練を受けた彼は、起動したロボット2体とともに暴走し始めた船を取り戻そうとする。軌道は大きく外れ、**未確認の惑星**への**軟着陸**しか道がなくなる——そこで待っていたのは、翠星でも、地球の地図でもない「赤い朝」だった。

## 物語の芯（時系列・設定用）

| 段階 | 内容 |
|------|------|
| 1. 巡航 | 翠星入植前哨任務。悠真は操縦席、他2名は冬眠継続（または復帰スケジュール直前） |
| 2. 復帰トラブル | 冬眠ポッド2基の**復帰シーケンス異常**（生命サイン喪失）。悠真は応急手当・記録するが**2名とも回復不能** |
| 3. 連鎖 | 船体システムへの影響（電力・ナビ・推進の乱れ）が重なり、**軌道が大きくずれる**（原因は「復帰トラブル単独」か「別故障の同時発生」かは**調査テーマ**） |
| 4. 制御 | 悠真＋**起動済みルーチェ・ピコ**でブリッジを分担。ロボットがレバー／パネルを操作し、悠真が判断と最終承認 |
| 5. 軟着陸 | 燃料・推力に余裕なし。**未確認惑星**の大気圏へ。**軟着陸手順**を試みる（着陸脚・逆噴射・姿勢制御） |
| 6. 着地後 | **エンジン一部破損**（詳細はこれから調査）。翠星ではないことを確認。2名の眠りきったポッド／記録の扱いは物語の重みとして残す |

## 世界設定

| 項目 | 内容 |
|------|------|
| 年代 | 22世紀半ば（レトロな船内UI・銀色ユニフォームは「古典的宇宙船」の伝統） |
| 地球 | 人口圧・気候対策のため、**翠星**への段階的入植を計画。前哨船は**人間3＋ロボット2**の小隊（冬眠で長距離航行） |
| 翠星（目標） | 海洋・緑地あり。大気は改造前提だが、**前哨基地の建設地点**まで座標が確定済み |
| 誤着惑星（仮称・**荒星（あらぼし）**） | 赤褐色の荒れ地、薄い大気、昼夜の寒暖差が激しい。翠星のデータと一致しない |
| 船 | **円盤型前哨船「リング・ブリッジ」**（全長約50m級・3脚着陸脚）。下部に小型探索車**「トレッド・ゼロ」**を収納（キャタピラ式） |
| 故障（着陸時） | 冬眠復帰トラブルと連鎖した**航法・推進の乱れ**、軟着陸時の衝撃で**主エンジン系の一部が破損**（損傷範囲・部品名は**未確定・これから調査**）。再離陸・通信には修理が前提 |

### 風見 悠真（かざみ ゆうま）・30歳・男性・パイロット兼前哨隊長

- **外見:** 短髪、やや日焼け。銀色の前哨ユニフォーム（胸に**翠星前哨**のワッペン）。左腕に古いアナログ腕時計（地球の祖父の形見）。
- **性格:** 冷静だが、冗談を一言入れると自分が落ち着く。完璧主義より**「今日はここまで」**派。仲間を失った直後は無言が長くなる。
- **訓練:** **統合非常事態訓練**（着陸逸脱・生命維持喪失・誘導不能・単独操縦）を修了。訓練シミュレータでは**ロボット2体と共同操縦**の科目あり。
- **役割:** 軌道逸脱後の**軟着陸判断**、ロボット2体との**制御分担**、着地後の修理・生存の最終責任者。

### 自立型ロボット・ルーチェ（Luce）・**丸い顔**・操縦／修理

- **外見:** **C-3PO型の人型**（細い金属胴・関節のある手足）。頭は**丸いフェイスプレート**（目は発光ライン2本）。背中に工具ホルダー可。
- **手:** 指付きの**操縦用ハンド**。ブリッジのレバー・スティック・パネルを人間と同様に操作できる（悠真の代わりに着陸手順を実行可能）。
- **声:** 低め・丁寧。日本語と英語を混ぜることがある（旧型OSの名残）。
- **口癖:** 「確率を申し上げます」「その配線は、触る前に遮断しましょう」
- **役割:** 航法データ照合・**「それは翠星のデータと一致しません」**。エンジン室の**破損調査**と修理計画の立案。

### 自立型ロボット・ピコ（Pico）・**四角い顔**・操縦／修理

- **外見:** 同じく**C-3PO型の人型**。頭部は**四角いフェイスプレート**（角ばった額、直線的な口ライン）。ルーチェよりやや小型でも**全身人型**（台座・多脚ではない）。
- **手:** ルーチェと同様の**操縦・整備用ハンド**。狭いエンジン室でのボルト回し・配線交換向き。
- **声:** 軽快・早口。たまに言い過ぎてルーチェに止められる。
- **口癖:** 「三十秒で直します！……たぶん！」「四角い頭は狭い場所に強いです」
- **役割:** **破損エンジン部分**の実働修理・部品取り外し・**トレッド・ゼロ**の出動準備。ギャグと現場の橋渡し。

### ロボット2体の共通仕様

| 項目 | 内容 |
|------|------|
| タイプ | 自立型・人型（C-3PO**風**／本作オリジナル） |
| 操縦 | 人の代わりにロケット操縦可能。悠真1人になった後は**ブリッジで2席分の操作を分担** |
| 起動 | 冬眠トラブル後、**起動できた2体**が制御試行に参加（3体目ロボットがいる設定にはしない） |
| 不時着後 | **エンジン一部破損**の応急処置→詳細調査を2体で分担 |
| 未決定 | 破損した具体部位名、冬眠事故の直接原因、交換部品の在庫、修理に必要な話数 |

## 第1話「赤い朝」――4ページ・ネーム（**旧案・執筆保留**）

> 以下は旧たたき台。**人間3名（2名死亡）・人型ロボ2体・軌道逸脱・軟着陸・エンジン破損**に合わせ、着手時に全面差し替えする。今は書き始めない。

**トーン:** 冒頭はテレビのオープニング風（ナレーション1コマ）→ 緊張 → 着陸 → 静寂 → 不安のオチ

---

### 1ページ（横4コマ）

**コマ1（大・上）**  
船外：銀色の円盤船が星空を滑る。遠方に**青緑に見える惑星**（翠星）。  
ナレーション（枠外）:「西暦2187年。人類は、第二の故郷を求めていた。」

**コマ2**  
ブリッジ内。レトロなトグルスイッチと丸いモニター。悠真がシートに座り、コーヒー片手に航路を確認。  
悠真:「あと六時間で翠星軌道。……今日のコーヒー、ちょっと苦いな」

**コマ3**  
ルーチェがドーム頭を回し、ピコが天井の配線を叩いている。  
ピコ:「苦いのは豆です！ 僕の配線は甘いです！」  
ルーチェ:「悠真さん、補助推進の圧力が0.3％低下。許容範囲内ですが、記録します。」

**コマ4（横長・警告）**  
モニターが赤点滅。**NAV PHASE ERROR**  
効果音: キーン！

### 2ページ（縦3コマ）

**コマ1**  
悠真がコップを置き、両手でレバー。  
悠真:「ルーチェ、翠星は？」  
ルーチェ:「正面にあります。しかし……**私たちは、翠星に向かっていません。**」

**コマ2（斜め・動き）**  
船体が振動。ピコが工具を散らしつつ壁につかまる。  
ピコ:「うわっ、これは“たぶん”じゃない！」  
ナレーション:「故障は、道を一つだけ残した。――下へ。」

**コマ3**  
悠真の顔・アップ。汗。背景に惑星が**赤褐色**に変わっていく。  
悠真:「着陸モード。全員、席に固定。……祖父の時計、止まらないでくれ。」

**コマ1（ページの8割）**

**コマ2**

ピコ:「……生きてます？」  
悠真:「生きてる。……翠星の景色、こんなじゃなかったな。」

### 4ページ（4コマ・オチ）

**コマ1**  
船外。赤い空、二つの小さな月。キャタピラ探索車のガレージドアが開き始める。  
ルーチェ（通信）:「大気分析完了。呼吸可能範囲。ただし**翠星のシーケンスと一致率12％**。」

**コマ2**  
悠真がヘルメットを持ち、トレッド・ゼロの窓から外を見る。  
悠真:「つまり、迷子だ。」  
ルーチェ:「正確には、**入植前哨としては、迷子です。**」

**コマ3**  
ピコがアンテナを立て、砂の中の**折れた地球製ビーコン**を発見（半分埋まり）。  
ピコ:「……これ、うちの世代の部品じゃない。もっと古い。」

**コマ4（小・余白多め）**  
悠真の後ろ姿。赤い地平線。  
悠真:「まずは一杯。……コーヒーが冷める前に、名前をつけよう。この星を。」  
ルーチェ（小さく）:「**荒星**と記録しました。次話、トレッド・ゼロ出動。」
