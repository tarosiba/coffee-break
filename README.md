# Coffee Break ☕

仕事の合間にひと息つける、ゲーム＆雑談アプリです。

## 機能

- **ミニゲーム** — じゃんけん、数当て、三目並べ
- **雑談ルーム** — ニックネームを設定して気軽にチャット（Coffee Bot がお相手）

## 技術スタック

- React 19 + TypeScript
- Vite
- Tailwind CSS 4

## セットアップ

```bash
npm install
npm run dev
```

ブラウザで http://localhost:5173 を開いてください。

## スクリプト

| コマンド | 説明 |
|---------|------|
| `npm run dev` | 開発サーバー起動 |
| `npm run build` | 本番ビルド |
| `npm run preview` | ビルド結果のプレビュー |
| `npm run lint` | ESLint 実行 |
